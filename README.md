# Retro Konsol

NES, SNES, Game Boy / Color ve Game Boy Advance oyunlarını çalıştıran Android uygulaması.
Oyun içermez; kullanıcı kendi (yasal) oyun dosyalarını ekler.

Emülasyon motorları (libretro): FCEUmm (GPL-2.0), bsnes-mercury (GPL-3.0), Gambatte (GPL-2.0), VBA Next (GPL-2.0).
Bu uygulamanın kaynak kodu bu depoda yayımlanmıştır (GPL gereği).

Derleme: GitHub Actions (`.github/workflows/konsol.yml`), dal: `konsol`. Çıktılar `konsol-apk` dalına konur.
